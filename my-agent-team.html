Parallel A

④ 다른 입력 × 다른 에이전트 · 합류: 코드 3
  • 2-a NVMe Spec
  • 2-b Spec Gap
  • 2-c Confluence 제품 사양

Parallel B

④ 다른 입력 × 다른 에이전트 · 합류: 코드 6
  • 4 Fail 항목 분석
  • 5 검토 필요 항목 문의 작성

Router

위치: 코드 3 이후 · 조건: 필드별 판정 상태
  • Pass → AI 호출 없이 코드 6
  • Fail → AI 4
  • 검토 필요 → AI 5
  • 검토 필요 0건 → AI 5 호출 안 함
  • Fail 0건 → AI 4는 종합 의견만 작성

Gen / Eval

2-a ↔ 2-a-E · 2-b ↔ 2-b-E · 2-c ↔ 2-c-E · 최대 2회
  • ① 모든 필드에 기대값 또는 '정의 없음 / TBD' 명시
  • ② 모든 기대값에 근거 문서(문서명·위치) 표시
  • ③ 기대값이 근거 원문과 일치 (단위·비트 변환 포함)

PASS / FAIL 처리

  • 모든 기준 충족 → PASS → 코드 3
  • 하나 이상 미충족 → FAIL → 문제 필드·사유를 같은 갈래 Generator에 전달해 수정 후 재검토
  • Evaluator는 직접 수정하지 않고 검토 결과만 전달
  • 2회 초과 FAIL → 해당 필드 '검토 필요' 표시 후 코드 3
